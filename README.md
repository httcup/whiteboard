# 白板 · Board

打开就是一块全屏白板：无限画布、手绘、流程图、便签，全部在浏览器本地运行，**零依赖、零构建、零上传**。

**在线使用：<https://httcup.github.io/whiteboard/>**

## 功能

- **工具**：画笔（贝塞尔平滑）、选择/移动、直线、箭头、矩形、椭圆、菱形、文字、彩色便签、橡皮、平移
- **无限画布**：滚轮/双指捏合缩放（15%–500%），空格或平移工具拖拽，Shift 拖矩形/椭圆锁定正形
- **编辑**：双击文字/便签修改，Delete 删除，撤销/重做（Ctrl+Z / Ctrl+Shift+Z，60 步）
- **快捷键**：V/P/L/A/R/O/D/T/N/E/H 一键切工具
- **导出 PNG**：按内容裁边，最长边 2400px，2x 高清
- **导出 PDF**：按内容比例自动选 A4 横/纵向，等比居中；图像以无损 FlateDecode 嵌入（手写 PDF 生成器，不引入任何库）
- **自动保存**：内容实时存入本机浏览器（localStorage），刷新、关掉再打开都在；底部有保存状态指示（保存中 / 已存本机 HH:MM / 存储已满），关页面前强制落盘。需要文件时再点「导出 PNG / PDF」。不联网、不上传。

> 注意：自动保存按「域名 + 浏览器」隔离——在 GitHub Pages 和 Cloudflare Pages 两个地址打开的是两份独立的画布；换浏览器或清浏览器数据也会丢失，重要内容请导出 PDF/PNG 留档。

## 快捷键速查

| 键 | 功能 |
|---|---|
| P / V / L / A / R / O / D | 画笔 / 选择 / 直线 / 箭头 / 矩形 / 椭圆 / 菱形 |
| T / N / E / H | 文字 / 便签 / 橡皮 / 平移 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Delete | 删除选中 |
| 空格 + 拖动 | 平移画布 |
| 滚轮 / 双指 | 缩放 |

## 部署

纯静态文件（`index.html` + `app.js` + `styles.css`），任何静态托管均可：

```bash
# 本地预览
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 隐私

所有绘制内容只存在于你的浏览器 localStorage，导出在本地完成，没有任何网络请求（CSP 已禁用全部远程连接）。
